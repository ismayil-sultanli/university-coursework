# University Coursework

Small coursework tasks and exercises from my university studies in **C, Java, Python and PowerShell**: data structures and algorithms written from scratch, numerical methods, machine-learning optimizers, games and desktop applications.

For my larger projects, see my LinkedIn profile.

Every C program builds and passes the automated checks in `run_tests.sh`; CI runs them on every push.

| # | Project | Stack | Highlights |
|---|---------|-------|------------|
| 01 | [C Algorithms & Systems](01-c-algorithms-and-systems/) | C, Python | AVL-tree records database, call-center queue/stack simulation with expected-output tests, flight runway scheduler, BST + deque/queue programmes, numerical methods with a function parser (bisection, Newton-Raphson, Gauss, Simpson…), GD / SGD / Adam optimizers from scratch with t-SNE visualisation, 3-player Reversi, board game with undo and save files |
| 02 | [Java OOP Projects](02-java-oop-projects/) | Java, Swing | Clinic reservation system with GUI and custom exceptions; playable Swing Tetris |
| 03 | [PowerShell File Toolkit](03-powershell-file-toolkit/) | PowerShell 7 | Advanced functions with `CmdletBinding`, pipeline input, parameter validation and comment-based help: folder report by file type and duplicate-file finder |
